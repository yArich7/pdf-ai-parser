# 提示词说明

这个目录存放本项目的核心资产——提示词。解析器与渲染只是“壳”，决定输出质量的是这里。

## 文件与用途

- `type_router.md`：文档类型识别。输入文档元信息 + 首页渲染图，输出 `doc_type / confidence / evidence / routing`，决定走哪条类型流水线。
- `drawing_report.md`：图纸类型的主提示词。输入图纸渲染图（可切片）+ 文本抽取结果，输出《图纸识别报告》（尺寸及公差 / 材料及组成 / 工艺及检验 / 待补充确认）。

## 使用约定

- 模型：优先用视觉模型（GPT-4o / Gemini / Qwen2.5-VL）；纯文本模型时只传入文本抽取结果，并明确提示“以文本为准”。
- 图片：图纸必须渲染成足够分辨率的图片；A0 大图需切片或分区域喂入，否则小字读不清。
- 输出解析：类型识别提示词的输出直接 JSON.parse；图纸报告提示词的输出为 Markdown，渲染成报告（PDF/Word）时用 ReportLab / pandoc。
- 新增类型：仿照 `drawing_report.md`，新增 `<类型>_report.md`，并在 `type_router.md` 的枚举里登记。
